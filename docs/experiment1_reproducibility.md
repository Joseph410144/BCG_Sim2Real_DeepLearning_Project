# Acquisition provenance and HeartV6 Experiment 1

This implementation assumes one measured person with repeated physical recordings. Historical `Subject_N` tokens are parsed as legacy dataset IDs, never as independent people. Generated manifests contain personal file-level metadata and remain under the ignored `reports/` directory.

## Acquisition manifest

The preprocessing source at `../Dataset/BCG/DeepLearningData/make_training_data.py` slices each continuous `*_heart.npy` source into contiguous 1,000-sample windows. The manifest generator matches each window to source candidates by basename and then verifies that:

- window BCG equals source channel 2 over `[start:end]`;
- window ECG equals source channel 0 over `[start:end]`;
- adjacent windows share the continuous-source dependency/split group;
- hashes, logical identifiers and sample ranges do not indicate duplicates or overlap.

It does not infer a higher recording-session boundary. `recording_session_id` therefore remains `UNKNOWN` until acquisition provenance establishes that grouping.

```bash
python generate_acquisition_manifest.py \
  --output-dir reports/acquisition_manifest_<run_id>
```

The output contains a private `manifest.csv`, `validation.json`, and `run_metadata.json`. Output directories must be new; the command refuses to overwrite a prior run. The public row schema is `schemas/acquisition_manifest.schema.json`.

## Controlled amplitude-modulation experiment

The synthetic DSP experiment evaluates

`x(t) = [1 + m cos(2 pi f_h t)] cos(2 pi f_c t) + n(t)`

under a fixed grid of carrier frequency, known modulation frequency, modulation depth, SNR and random replicates. It compares the raw spectrum with bandpass plus full-wave rectification, Hilbert envelope, and squared-energy extraction.

```bash
python run_controlled_am_experiment.py \
  --config configs/experiment1_am.json \
  --output-dir reports/track_a/am_<run_id>
```

This demonstrates recoverability under an AM model only. It is not evidence that real BCG is generated by this exact mechanism and is not simulated biological diversity.

## Representative physical-recording traces

Cases are selected from precomputed audited baseline results using the fixed classes and seeded rule in `configs/experiment1_real_trace.json`. Selection includes low-error, moderate-error and gross-error cases while prioritizing distinct legacy dataset IDs and verified continuous sources.

```bash
python run_heart_v6_trace_experiment.py \
  --manifest reports/acquisition_manifest_<run_id>/manifest.csv \
  --config configs/experiment1_real_trace.json \
  --output-dir reports/track_a/heart_v6_trace_<run_id>
```

Each case exports compressed numerical arrays, JSON diagnostics, and PNG/PDF figures showing the preprocessed waveform, spectrogram, six band outputs, rectified representations, per-band and fused spectra, harmonic candidates, narrowband refinement, and detected peaks. Figures can be regenerated from the stored arrays without rerunning HeartV6.
